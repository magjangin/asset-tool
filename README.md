# asset-tool (Spine Part Splitter)

뮤즈대시 같은 Unity 게임에서 추출한 **Spine 텍스처(PNG)를 파츠별 PNG로 잘라내는** 데스크톱 도구입니다.
Avalonia UI + SkiaSharp로 만들었습니다.

## 기능

### PNG 자동 감지로 분리
- 투명하지 않은 픽셀(알파 10 이상)끼리 8방향으로 이어진 덩어리를 하나의 파츠로 잘라냅니다.
- 같은 사각형 안에 들어온 다른 덩어리의 픽셀은 가려서 섞이지 않게 합니다.
- 4픽셀 미만의 작은 점은 무시합니다.

### 아틀라스(.atlas)로 분리
- libgdx/Spine `.atlas` 텍스트 형식을 읽습니다. `.atlas.txt`도 지원합니다(AssetStudio 추출본).
  - 구형: `xy` / `size` / `orig` / `offset` / `index`
  - 신형: `bounds` / `offsets`
- 회전된 리전(`rotate: true` / `90` / `270` 등)을 원래 방향으로 되돌립니다.
- 열린 PNG와 파일명이 같은 페이지를 골라 분리합니다. 없으면 첫 페이지를 씁니다.
- 페이지 범위를 벗어난 리전은 제외하고 상태줄에 알려 줍니다.
- 선택 옵션:
  - **가장자리 배경 자동 제거(누끼)**: 모서리 색과 비슷한 픽셀을 테두리에서부터 지웁니다(허용 오차 조절).
  - **내부에 작게 낀 다른 파츠 제거**: 크기가 훨씬 작은 다른 색 덩어리를 지웁니다.

### 내보내기
- 체크한 파츠만 선택한 폴더에 PNG로 저장합니다.
- 목록에서 파츠 이름을 바로 고칠 수 있습니다.
- 파일명에 쓸 수 없는 문자(`/` 등)는 `_`로 바꿉니다.
- 같은 이름이 겹치면 `_2`, `_3`을 붙여 서로 덮어쓰지 않게 합니다.

## 빌드 / 실행

필요: [.NET 10 SDK](https://dotnet.microsoft.com/download)

```bash
dotnet run --project "asset tool/asset tool.csproj"
```

Visual Studio에서는 `asset tool.slnx`를 열면 됩니다.

## 구조

| 파일 | 역할 |
| --- | --- |
| `MainWindow.axaml(.cs)` | 화면과 버튼 동작 |
| `AtlasParser.cs` | `.atlas` 파서 |
| `PartSplitter.cs` | 알파 덩어리 기반 자동 분리 |
| `BackgroundCutout.cs` | 색 기반 누끼 / 작은 덩어리 제거 |
| `PartItem.cs` | 파츠 목록 항목 |

## 알려진 문제

- 색 기반 누끼가 **모서리가 투명한 어두운 파츠를 통째로 지웁니다**. 투명한 모서리를 "검정 배경"으로 착각하기 때문입니다. 노트의 `shadow`(어두운 타원)는 100% 지워집니다.
- 누끼의 "거의 다 지워지면 중단" 안전장치가 투명 영역을 잘못 세어서 잘 걸리지 않습니다.
- 작은 덩어리 제거가 색으로 덩어리를 나누기 때문에 동공·하이라이트 같은 안쪽 디테일까지 지웁니다.
- 180° 회전된 리전은 결과 크기가 뒤바뀌어 깨집니다.
- 잘못된 아틀라스/PNG를 열면 예외 처리가 없어 프로그램이 종료됩니다.
- 아틀라스에 사용자 정의 필드가 있으면 가짜 리전으로 잘못 인식합니다.
- 내보낼 때 폴더에 같은 이름의 파일이 있으면 경고 없이 덮어씁니다.
- PNG를 premultiplied 형식으로 읽어서 거의 투명한 픽셀의 색이 손실됩니다.
- 여러 파일을 한 번에 처리하는 기능이 없습니다.
